# midicn · 音乐知识

这是 [音乐知识](https://home.midicn.com/) 的双语内容真源；网站产物位于 [midicn/home](https://github.com/midicn/home)。

midicn 音乐知识的入口 —— 从入门出发，连接乐理、乐器、全球音乐史、音频制作、AI 做音乐与词典。

每条内容使用 Markdown 与 YAML 元数据，同一文件内以 `::: zh` 和 `::: en` 编写中英两版。
`instances` 指向曲库中的真实曲目，`[[类型:ID]]` 由实体注册表解析为站内或跨站链接。

- `_portal.json`：首页导航配置。

首页配置属于构建输入，与正文一起维护。作者笔记和进度文件不属于公开内容。
