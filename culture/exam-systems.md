「考到八级」经常被当成一句等级语言。但**考级测的是一组被抽样的能力，不是难度**——不同体系抽的样本完全不同。

## 考级实际抽的几种能力

一次典型的器乐考级大致会抽这几样：

1. **视奏** —— 给你从没见过的谱，当场读出来。测的是**读谱速度与视奏技巧**；
2. **技巧乐理** —— 音阶、琶音、和弦（有时含调号与音准要求）。测的是**基础规范化程度**；
3. **乐曲演奏** —— 通常两首，一首对比性不强、一首有表现力要求。测的是**完成度**；
4. **乐理笔试** —— 一些体系有，测的是**术语与规则**；
5. **听觉／唱奏** —— 部分体系有，测的是[[concept:ear-training|听辨]]。

**关键在于 5 个维度不一定都权重相同，有的体系甚至不考其中一项。**

## 一句话的问题

判断一个考级值不值得考，只问一句：

**它考的和我缺的是同一项吗？**

- 缺视奏能力 → 考级里视奏占比高的体系有用；
- 已经能背能弹、读谱慢 → 视奏项正是你该练的；
- 目标是考级之外的东西（作曲、伴奏、即兴）→ **考级覆盖不到那部分，练它是边际投入递减**。

**考级是抽样，不是全测。** 拿它当"完整评价"是误用。

## 考级制度被诟病的地方

几条常见的批评，判断时值得知道：

- **曲目偏窄**：规定曲目容易变成"考级曲目"而不是"音乐"，演奏者熟悉曲目少；
- **评委主观**：不同考场评分差异可能大于同一个人前后的进步；
- **替代了长期练习**：把音乐学习变成"每年升级"的履历逻辑；
- **忽略伴奏与合奏能力**：考级几乎全是独奏科目。

这些批评中，**"考级曲目化"是最实在的一条**——如果学生只练规定曲目，考完就丢。

## 一个更实际的用法：把它当诊断

比"要不要考级"更有用的问法是：

**用考级当一次体检，而不是当终点。**

- 视奏分低 → 知道接下来半年该练什么；
- 音阶总错 → 问题在基础规范化，不在曲子难度；
- 乐曲完成度不够 → 是演奏问题，不是曲子选得难。

**这比"我该考几级"更有决策价值。** 上面的实例里那些渐进练习曲正是这类体检的教材形态。

"Got to grade eight" is usually spoken as if it were a single scale of difficulty. But **an exam samples a set of abilities; it does not measure difficulty** — and different systems sample completely different things.

## What an exam actually samples

A typical instrumental exam draws from:

1. **Sight-reading** — a score you have never seen, read on the spot. Tests **reading speed and sight-reading technique**;
2. **Technique/theory** — scales, arpeggios, chords (sometimes with key signatures and intonation demands). Tests **how far your basics are standardised**;
3. **Performance** — usually two pieces, one less contrasting, one requiring expression. Tests **completeness**;
4. **Written theory** — present in some systems. Tests **terminology and rules**;
5. **Aural/singing** — in some systems. Tests [[concept:ear-training|ear training]].

**The point is that these five are not necessarily weighted the same — some systems test none of one of them.**

## The one question worth asking

To decide whether an exam is worth taking, ask one thing:

**Does what it test coincide with what I lack?**

- If sight-reading is your gap → a system with a heavy sight-reading component helps;
- If you can play by heart but read slowly → that component is exactly what you should drill;
- If your goal lies outside exams (composition, accompaniment, improvisation) → **exams do not cover that, so practice there has rapidly diminishing returns**.

**An exam is a sample, not a full assessment.** Treating it as a complete evaluation is a misuse.

## Where the system is criticised

A few common criticisms, worth knowing when judging:

- **Narrow repertoire**: prescribed pieces easily become "exam pieces" rather than music, and players end up knowing few pieces;
- **Subjective marking**: differences between venues can exceed one player's improvement over time;
- **It substitutes for sustained practice**: music study turns into an annual-upgrade CV logic;
- **It ignores accompanying and ensemble skills**: exams are almost entirely solo subjects.

Of these, **"exam repertoire" is the most concrete**: if a student only practises the prescribed list, it all ends up discarded after the exam.

## A more useful framing: use it as a diagnosis

A better question than "should I take exams" is:

**Use the exam as a check-up, not as a finish line.**

- Weak sight-reading → you now know what to work on for six months;
- Scales always wrong → the problem is standardised basics, not the difficulty of the piece;
- Performances feel unfinished → that is a playing problem, not a hard-repertoire problem.

**That is far more decision-relevant than "which grade should I aim for".** The progressive études among the examples above are exactly the textbook shape for this kind of check-up.
